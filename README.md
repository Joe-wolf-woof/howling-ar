# ハウリング（Howling）

部屋にオオカミが住んでいる——AIキャラクター「ハウル」に会いに行く WebAR アプリ。
第二作。第一作『Spatial AI NPC』（仮説検証の実験作）は凍結し、本作はユーザー目線の「作品」として作る。
コンセプト設計: `~/workspace/goals/xr-ai/files/new-ar-app-concept.md`

ハウルは X（@AgentName_Howl）で発信しているのと同じ個体で、自分の投稿と過去の出来事を覚えている。
X 側の運用エンジンは別リポジトリ `howl-agent`（Python）。

## N1（殻と登場）で入っているもの

- 登場フロー：スタート画面 → カメラ開始 → **記憶を踏まえた挨拶**（初回／再訪で変化。最新の X 投稿やポトスのエピソードに触れる）
- 会話：テキストで話しかけると、ペルソナ v0.4（ワガハイ／家の人間）＋記憶コンテキストで返答し、音声で読み上げる
  - Gemini API キー未設定時はモック返答（ハウルの声）で動作
- タップ配置：地面をタップするとハウルが歩いて移動する（遠いときは Trot で速く）
- 撮影モード：UI を隠してカメラ映像＋ハウルを合成し、PNG で保存できる
- 数値パネルなし・常時推論なし（設計原則どおり、検知は N2 でイベント駆動として入れる）

## N2（見せる・覚える）で入っているもの

- 「見せる」ボタン：カメラで物を見せると、ハウルが映像を見て反応する（Gemini 視覚。キー未設定時はモック応答）。入力欄に言葉を添えることもできる
  - カメラが入っていないときは案内を出す。AR（WebXR）中は通常モード専用
- 「覚える」：見せたときの反応はブラウザの localStorage（`howling_episodes`、最新50件）にエピソードとして残り、次回以降の会話文脈に直近3件が合流する（「前に見せてもらった物」に触れられる）
- 書き出し：設定パネルの「見せた記憶を書き出す」から `howling-episodes.json`（`{date, kind: 'shown', text}` の配列）をダウンロードできる。将来 howl-agent のエピソード記憶へ取り込むための連携フォーマット

## 動かし方（ローカル）

```bash
cd ~/workspace/projects/howling
python3 -m http.server 8970
# ブラウザで http://localhost:8970/ を開く（スマホ実機は同一LANのIP経由 or 公開デプロイで）
```

Gemini API キーは画面下の「設定」から入力（ブラウザ内にのみ保存。『ハウリング』専用キーを発行して使う）。

## モデル

- 仮モデル: `assets/models/avatar.glb` — TRELLIS.2 生成 → 軽量化 → afk.ai 四足オートリグ（Walk / Trot / Run の3クリップ）
  - 感情クリップ（Idle / Sit / Howl 等）は afk.ai の無料枠の都合で未取得。現状の感情表現はモデル全体のプロシージャルモーションで代替
- **12月に Tripo Pro 生成モデル（マルチビューHD）へ差し替え予定**。差し替えは `avatar.glb` の置換＋クリップ対応の確認のみで済む設計

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` / `css/style.css` | キャラ主役 UI（吹き出し、大きなボタン、撮影モード） |
| `main.js` | 配線（登場・会話・タップ配置・撮影） |
| `ar-viewer/` | scene / avatar（GLB正規化） / camera（第一作から流用） |
| `ai-agent-engine/` | gemini-client（ペルソナ＋記憶文脈、モデルフォールバック） / speech |
| `motion-controller/` | 感情→クリップ＋プロシージャル（Walk/Trot 対応を追加） |
| `memory/greeting.js` | 記憶の静的エクスポートから挨拶と文脈を生成 |
| `data/memory.json` | howl-agent のエピソード記憶の静的エクスポート（N1 は読み取り専用） |

## フェーズ

- **N1（殻と登場）**: 本書の状態
- **N2（見せる・覚える）**: 「見せる」＋ローカルエピソード保存＋書き出しまで実装済み（X ネタ候補フラグと howl-agent 同期は N3）
- **N3（連携と差し替え）**: howl-agent の記憶ストアと同期、X 発言を踏まえた挨拶、新モデル差し替え
